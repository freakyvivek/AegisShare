Security Features At a Glance

Zero-Knowledge Token Storage

Plaintext access tokens are returned only to creator and never saved in database; only SHA-256 hashes are persisted.

UTC TTL Expiry Enforcement

Access requests past expiration timestamp are rejected immediately and logged as denied events.

Download Ceilings & Revocation

Enforce single-use or limited downloads. Revoke access tokens on demand before expiry.

Sanitized Audit Logging

Sensitive credentials and presigned query strings are scrubbed before writing to immutable logs.
